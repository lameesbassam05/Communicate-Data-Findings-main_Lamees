# 2022 World Cup Data Analysis ⚽

This project is part of the requirements for the **Palestine Launchpad Program - Data Analysis Nanodegree**, featuring an exploratory and explanatory analysis of 2022 World Cup data.

## 📝 Project Description

This analysis aims to explore a comprehensive dataset of 2022 World Cup matches, containing specialized statistics such as on-field actions, tactical choices, and defensive maneuvers. The project covers the following key details:

- **Part One (Exploratory Analysis):** Focuses on understanding the data structure, cleaning the data, and analyzing distributions across various metrics. Univariate, bivariate, and multivariate analysis techniques were employed to explore team performance.
- **Part Two (Explanatory Analysis):** Presents key findings derived from the exploratory phase, focusing on delivering concise, actionable insights to support decision-making.

## 📊 Data Sources

The data used in this analysis comes from the `Fifa_world_cup_matches.csv` file, which includes detailed data for all 64 matches of the 2022 World Cup.

## 📈 Summary of Key Findings

- **Considerations and Objectives:** There is a relationship between specific metrics and match outcomes, though this varies across different areas of play.
- **Defensive Actions:** Defensive actions—such as "defensive pressure" and "ball recovery"—play a significant role in future match results.
- **Shooting Accuracy:** Teams that generate a higher volume of shots are more likely to score goals, highlighting the importance of consistent shooting.
- **Tournament Stages:** Variations in play (such as the number of groups and playing style) occur depending on the tournament stage (group stage vs. knockout stage).
